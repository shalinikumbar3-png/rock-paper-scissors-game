# Rock Paper Scissors Game

An interactive browser-based **Rock Paper Scissors** game built using HTML5, CSS3, and vanilla JavaScript. Play against the computer with instant move evaluation, dynamic visual feedback, and live score tracking.

## Features

* **Interactive Gameplay:** Click on Rock, Paper, or Scissors to play against a randomized computer opponent.
* **Live Scoreboard:** Tracks both User and Computer scores in real time across rounds.
* **Dynamic Status Messages:** Displays instant win, lose, or draw notifications after every move with color-coded feedback.
* **Responsive Design:** Clean, centered layout that works smoothly across desktop and mobile screens.
